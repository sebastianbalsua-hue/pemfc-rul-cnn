# ECSIM pem-dataset1

- Fuente: [https://www.kaggle.com/datasets/sepandhaghighi/proton-exchange-membrane-pem-fuel-cell-dataset](https://www.kaggle.com/datasets/sepandhaghighi/proton-exchange-membrane-pem-fuel-cell-dataset)
- GitHub: [https://github.com/ECSIM/pem-dataset1](https://github.com/ECSIM/pem-dataset1)
- Rol en el proyecto: Caracterizacion electroquimica y validacion del preprocesamiento.
- Contenido: curvas de polarizacion y espectroscopia de impedancia (EIS) sobre membrana Nafion 112 y MEA.
- Nota: no contiene trayectoria de degradacion ni etiquetas RUL. No se usa para entrenamiento de RUL.
