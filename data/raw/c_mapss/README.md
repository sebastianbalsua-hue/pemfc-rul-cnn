# NASA C-MAPSS

- **Fuente:** [https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/)
- **Rol en el proyecto:** Validación arquitectónica de la CNN causal-dilatada en un dominio con RUL nativa.
- **Contenido:** FD001–FD004. 21 sensores + 3 ajustes operacionales. Series run-to-failure.
- **Umbral de fallo:** RUL capping estándar de 125 ciclos.
