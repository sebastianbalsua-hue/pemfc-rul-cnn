# IEEE PHM 2014 Data Challenge (FCLAB/FEMTO-ST)

- **Fuente:** [https://eng.fclab.fr/ieee-phm-2014-data-challenge/](https://eng.fclab.fr/ieee-phm-2014-data-challenge/)
- **Rol en el proyecto:** Dataset principal de RUL en PEMFC.
- **Contenido:** FC1 (carga constante 70 A, entrenamiento) y FC2 (carga dinámica, pronóstico).
- **Variables:** voltajes U1–U5 y Utot, corriente, densidades, temperaturas, presiones, flujos, humedad.
- **Umbral de fallo:** caída del 10% en el voltaje inicial.
- **Descarga:** requiere solicitud formal en el enlace de FCLAB.
